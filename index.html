Умения Мученика

[ ⚜️ ] Завет
До первой смерти +100% входящего урона. Успех: 100% HP + награда + стигматы. Провал: 60% HP без бонусов стигмат.
[ ⚜️ ] Отречение
Пассивно отвергает положительные эффекты союзников. За каждый отвергнутый эффект: +2 стигматы.
[ ⚜️ ] Несение креста
50 стамины, КД 3. 50% полученного урона × крит возвращается врагу. Абсолютная версия: 100%, 2 хода. Прокачка: +1% урона Креста за уровень.
[ ⚜️ ] Мстительный дух / Воздаяние
1-е нажатие запоминает событие. 2-е: критическая физическая атака + воспроизведение. Повтор до воскрешения стоит 3 стигматы. Прокачка: +1% урона за уровень.
[ ⚜️ ] Самопожертвование
По себе: смерть + урон = текущее HP × крит. За союзника: смерть + щит союзнику = текущему HP.
[ ⚜️ ] Очищение
После воскрешения. 100 стамины, КД 4. Урон = физ. атака ×2 × крит. Бонусы от стигмат при успешном Завете.
